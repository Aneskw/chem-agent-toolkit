## Maintenance

- Curated package names use `<tool>-<action>-<task>`; folder and frontmatter names match.
- The prefix names the primary tool. Required supporting tools are documented inside each skill.
- `catalog.json` stores only relative package paths, primary task categories and source-paper DOIs.
- Names and descriptions are read from `SKILL.md`; they are not duplicated in the catalog.
- When changing a package or catalog entry, update the corresponding README row so its name, link and description match `SKILL.md`.
- Keep build receipts, quality reports and curation history outside this collection. Pipeline adoption manages the root registry; it does not update this collection catalog.
